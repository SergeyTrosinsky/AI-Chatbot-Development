# Чат-бот по вселенной «Гравити Фолз» (Gravity Falls RAG-Bot)

## Описание проекта

Проект посвящен созданию интеллектуального чат-бота для Telegram, способного отвечать на вопросы о мультсериале «Гравити Фолз». В основе системы лежит архитектура **RAG (Retrieval-Augmented Generation)**, которая объединяет мощь большой языковой модели (**GigaChat**) с достоверными данными из подготовленной базы знаний. Бот не просто «фантазирует», а находит релевантные факты в текстовой базе, что гарантирует точность ответов по лору сериала.

## Используемые технологии

- **LLM:** GigaChat API
    
- **Библиотеки:** `telebot` (pyTelegramBotAPI), `langchain` / `langchain_community`, `chromadb`
    
- **Среда:** Google Colab, Google Drive
    
- **Данные:** Текстовая база знаний (`gravity_falls_knowledge.txt`)

## Схема пайплайна

Процесс обработки запроса пользователя проходит через несколько этапов:

1. **Запрос:** Получение текстового сообщения от пользователя в Telegram.
    
2. **Retrieval:** Поиск наиболее подходящего отрывка в `gravity_falls_knowledge.txt` с использованием семантического анализа (ChromaDB).
    
3. **Augmentation:** Передача найденного контекста в промпт для GigaChat.
    
4. **Generation:** Получение аргументированного ответа от нейросети.

### Этапы реализации (Детальный разбор кода)

Процесс функционирования бота в `main.ipynb` можно разделить на три технологических этапа:

#### 1. Подключение и инициализация LLM (GigaChat)

На этом этапе устанавливается связь с моделью GigaChat. Мы используем библиотеку `langchain` для управления «памятью» и контекстом.

- **Что происходит:** Бот аутентифицируется через API-ключ, переданный из секретов Colab.
    
- **Ключевой код:**
    
```Python
from langchain_community.chat_models import GigaChat

# Инициализация модели: отключаем проверку SSL для стабильности в облаке
llm = GigaChat(credentials=userdata.get('gigachat_token'), verify_ssl_certs=False)
```

#### 2. RAG-пайплайн: Векторизация и поиск

Этот блок - мозг проекта. Поскольку GigaChat не знает специфических подробностей вашего текстового файла, мы создаем локальный индекс.

- **Что происходит:**
    
    1. Текст из `gravity_falls_knowledge.txt` нарезается на мелкие куски (chunks) через `RecursiveCharacterTextSplitter`.
        
    2. Эти куски преобразуются в математические векторы (эмбеддинги) и сохраняются в `ChromaDB`.
        
    3. Когда пользователь пишет вопрос, система ищет 3-5 фрагментов текста, наиболее близких по смыслу к запросу.
        
- **Ключевой код:**
    
```Python
# Поиск контекста: находим релевантные куски текста по вопросу пользователя
docs = vectorstore.similarity_search(query=message.text, k=3)
context = "\n".join([doc.page_content for doc in docs])
```

#### 3. Генерация ответа и работа бота

Здесь замыкается цепочка: контекст из базы знаний передается в GigaChat вместе с вопросом пользователя для формирования финального ответа.

- **Что происходит:** Бот использует `telebot` для прослушивания (polling) обновлений в Telegram. Как только приходит текст, он отправляется в функцию `answer(message.text)`, которая:
    
    - Извлекает контекст из ChromaDB.
        
    - Формирует системный промпт: _"Ответь на вопрос, опираясь строго на этот текст: [контекст]"_.
        
    - Получает ответ от GigaChat и пересылает его в чат пользователю.
        
- **Ключевой код:**

```Python
@bot.message_handler(func=lambda message: True)
def handle_message(message):
    # Формирование ответа через RAG-цепочку
    ans = answer(message.text) 
    # Передача ответа обратно в Telegram
    bot.send_message(message.chat.id, ans)
```
### Обработка сообщений (Telegram Bot)

Бот работает в режиме `polling`, постоянно отслеживая запросы пользователей и вызывая функцию генерации ответа.

## Как запустить проект

1. Откройте `GF.ipynb` в Google Colab.
    
2. Установите необходимые зависимости через `%pip install`.
    
3. Добавьте ваши ключи API (GigaChat и токен бота от @BotFather) в раздел **Secrets** вашего Colab.
    
4. Загрузите базу знаний `gravity_falls_knowledge.txt`.
    
5. Запустите ячейку с `bot.polling()`. Бот готов к работе!
